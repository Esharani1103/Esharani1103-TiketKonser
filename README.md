## 📖 Deskripsi

Website Tiket Konser merupakan aplikasi berbasis web yang dikembangkan untuk memudahkan pengguna melihat informasi konser dan melakukan pemesanan tiket secara online.

## ✨ Fitur

- Login & Register
- Informasi Konser
- Pemesanan Tiket
- Dashboard Admin
- Manajemen Data Konser

## 🛠️ Teknologi

- Laravel
- PHP
- MySQL
- Bootstrap

## 👥 Tim

Project ini dikembangkan secara berkelompok sebagai media pembelajaran menggunakan Laravel.
